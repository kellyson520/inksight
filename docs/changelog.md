# InkSight 版本迭代更新日志 (Changelog)

所有针对 InkSight（后端、Web 控制台、排版引擎、墨水屏协议）的重要演进与更新均按时间倒序归档于此。

---

### [2026-09-05] - 全局暗黑模式、微信读书增强、二维码展示与 520+ 组件发布

#### 新增特性 (Features)
- **Web 端全局黑暗模式（Dark Mode）与浅色蒙版深度自愈**：
  - 彻底修复暗夜模式下卡片框、模式列表框未变黑及半透明浅色蒙版突兀刺眼问题；
  - 完善 `webapp/app/globals.css` 中深色模式样式体系，统一 `Card`、`Dialog`、模态弹窗与 `input/textarea/select` 表单的深暗底色与微亮边框；
  - 保护 `.eink-paper` 墨水屏预览画纸的真实黑白对比度，优化暗色毛玻璃与悬浮微光。
- **远程 CPA 与 Keeper 额度监控（非本地多实例架构）**：
  - `core/cpa_keeper_service.py` 全面支持远程 `cpa_url` 与 `keeper_url`，可通过环境变量或 Web 设置面板单设备动态覆盖；
  - 自动适配远程 HTTP REST API 认证、额度重置倒计时拉取与本地 SQLite 直连双重自适应回退。
- **全新生活效率模式发布**：
  - **四象限待办矩阵（`TODO_MATRIX`）**：艾森豪威尔 4 象限时间管理桌面看板，按重要度与紧迫度双轴网格排版，实时汇总今日达成率与效能名言；
  - **生活与健康打卡（`HABIT_TRACKER`）**：追踪每日 8 杯水分摄入（进度条）、久坐站立拉伸、深度阅读 30 分钟、作息规律与近 7 天坚持点阵。
- **Docker 全量热挂载开发环境与秒级热重载**：
  - `docker-compose.yml` 配置 `backend/`、`docs/`、`webapp/` 全量代码挂载；
  - 容器内 Supervisord 启动 Uvicorn `StatReload` 监听，修改代码后 0.3s 自动生效，彻底免除反复重构镜像消耗；
  - 容器内外共享同一套数据库、缓存与上传文件。
- **排版引擎与抖动自愈算法增强**：
  - **原生抖动自愈降级**：`core/native_dither.py` 接入 Atkinson/Floyd-Steinberg 双向自愈降级，消除底层动态链接库异常崩溃风险；
  - **双栏与卡片边界安全**：`two_column` 与 `card` 增加屏幕底部视口溢出截断保护，极窄可用宽度下自动优雅退化为单栏堆叠；
  - **中日韩避头尾排版精进**：修复单个孤立汉字后接全角标点的折行问题，支持高对比度微悬挂与自适应拆分。
- **Docker 生产级单容器部署（All-in-One）**：
  - 打造全栈整合的一体化 Dockerfile 与 docker-compose.yml；
  - 集成 Python FastAPI 后端、Next.js Web 控制台与 Supervisor 进程自愈守护；
  - 挂载持久化数据卷，支持一行命令在 NAS、群晖、树莓派及云服务器极速跑通；
  - 新增《Docker 一键部署指南》（`docs/docker-deploy.md`）。
- **Web 端全局黑暗模式（Dark Mode）**：
  - WebApp（`https://kellson.dpdns.org:3001`）全面接入深色主题体系；
  - 顶部导航栏支持一键在日间模式、极客暗黑模式与跟随系统之间平滑切换；
  - 客户端首屏注入零闪烁防白屏脚本，全站组件与文档排版高对比度护眼呈现。
- **全新二维码渲染模式（`QR_CODE`）与原生矢量 Block**：
  - 实现纯二值化 `qrcode` 排版 Block，使用 `NEAREST` 像素级锐利采样，避免双线性插值模糊；
  - 支持网址跳转（`URL`）、Wi-Fi 扫码自动连网（`WIFI`）以及便签纯文本传递；
  - 模式布局采用左侧标题参数、右侧高容错清晰二维码的双栏卡片结构。
- **520+ 原生排版与矢量组件生态**：
  - 突破 520 个独立矢量排版组件里程碑，涵盖赛博朋克数据看板、自然天气、极客图表、折线图、K线图、甘特图等丰富元素；
  - 建立自动化尺寸度量体系（`measure_block_size`），彻底消除重叠与折叠；
  - 配套输出 `docs/layout-blocks-500.md` 全量组件画册。
- **多渠道推送与告警中心（Push Dispatcher）**：
  - 构建统一推送调度器，联动墨水屏急救插播、Bark、微信群机器人 Webhook 与 ServerChan；
  - 将灾害预警、网页变动监控与设备状态全链路打通。

#### 修复与优化 (Fixes & Performance)
- **微信读书推荐模式（`WECHAT_READ`）修复**：
  - 剥离失效的第三方图片反代，切换为原生高清直链，注入合规浏览器请求头；
  - 修复双栏排版器 `render_two_column` 对 `left_blocks` / `right_blocks` 的别名解析不匹配问题；
  - 彻底解决正文区域大面积空白（非白色像素覆盖率从 2,117 提升至 22,616）。
- **静态本地画库与字体平稳降级**：
  - 修复无外网 API Key 时 `ARTWALL` 相对本地路径协议解析报错的问题，实现秒级本地静态水墨画直读；
  - 国际音标字体缺失时优雅平稳降级至 `NotoSerifSC-Regular.ttf`，避免回退为系统简陋小字。
- **底层二值化向量加速**：
  - 使用 Pillow 点变换查表法（LUT）重构 `rgba_to_mono`，彻底替代双层循环逐像素取样，批量渲染速度提升数倍。

### [2026-09-04] - 黄金趋势模式、极客科技雷达与市场数据引擎

#### 新增特性 (Features)
- **黄金大盘走势模式（`GOLD`）**：
  - 接入实时黄金现货与期货行情，内置当日分时微型火花折线图（Sparkline）与双重走势指标。
- **极客科技雷达模式（`TECH_RADAR`）**：
  - 聚合前沿开源社区资讯，按 AI、后端、云原生等分类动态排版推送。
- **网页变动监听与灾害防御预警体系**：
  - 后端服务内置变动差分引擎，支持关键网页节点监视并在墨水屏即时插播。
