# Web 界面黑暗模式使用操作手册 (Dark Mode Manual)

InkSight Web 管理控制台与文档中心支持全面的**深色/黑暗模式（Dark Mode）**，为开发者在深夜调试、日常配置设备以及查阅文档提供高对比度、护眼且具沉浸感的极客视觉体验。

---

## 一、支持范围与特性

1. **全站自动适配**：
   - 顶部导航栏（Navbar）与悬浮毛玻璃特效；
   - 首页、在线刷机（Web Flasher）、模式广场（Discover）、设备配置（Config）；
   - 在线预览（Preview）、无设备体验面板；
   - 官方完整文档中心（Docs Prose、代码高亮框、引用块、技术参数表格）。
2. **零闪烁加载（Anti-Flicker）**：
   - 首次访问或刷新页面时，浏览器会在 HTML 解析阶段直接读取本地偏好，杜绝亮白色闪屏。
3. **三种主题随心切换**：
   - **日间模式（Light）**：清雅高对比度水墨白纸风格；
   - **暗黑模式（Dark）**：极客沉浸深空灰（`#09090b` / `zinc-950`）低眩光配色；
   - **跟随系统（System）**：自动响应 macOS、Windows、iOS、Android 系统的夜间模式调度。

---

## 二、如何切换黑暗模式

### 1. 桌面端（Desktop）
在页面顶部导航栏右侧，找到**主题切换按钮**（显示为太阳 ☀️、月亮 🌙 或笔记本电脑 💻 图标）：
- 点击按钮即可在 **日间模式 ➔ 暗黑模式 ➔ 跟随系统** 之间快速循环切换；
- 鼠标悬停可显示当前激活的主题状态。

### 2. 移动端与平板（Mobile / Tablet）
在手机或狭窄屏幕打开网页时：
- 右上角汉堡菜单旁边直接常驻主题快捷切换图标；
- 展开折叠菜单后同样可以随时一键切换。

---

## 三、偏好持久化与跨标签页同步

- 您的主题选择会自动加密持久化存储在浏览器的 `localStorage.getItem("inksight-theme")` 中；
- 当您在同一浏览器打开多个标签页或后续重新访问 `https://kellson.dpdns.org:3001` 时，无需重新设置，网站将始终保持您最舒适的界面风格。
