# 通用开放 Webhook 数据卡片与全网热榜 Provider 架构设计

## 1. 目标
进一步将 InkSight 打造成开放生态中心：
1. **硬件接口保持完全不变**：ESP32 墨水屏设备端拉取 `/api/render` 与 `/api/screen` 依然接收标准 1-bit BMP 图片，固件零改动；
2. **通用 Webhook 开放数据卡片 (`WEBHOOK`)**：
   - 彻底打破固定排版限制，支持任意第三方系统（Home Assistant 传感器、服务器监控、自建脚本、跑步数据、打卡通知等）通过 `POST /api/open/device/{mac}/data` 推送任意指标；
   - 包含：卡片标题、主指标大字（如 "24.5°C" 或 "Load 0.42"）、副指标/副标题、状态标签、3组键值对明细、底部时间戳；
   - 支持本地 fallback 示例（如家庭环境温湿度数据），离线无推送时同样优雅展示；
3. **全网热榜模块 (`HOTLIST`)**：
   - 支持微博热搜、知乎热榜、B站热门、GitHub Trending、百度热搜等平台自由切换；
   - 抓取 Top 5 热门话题并排版为优雅的墨水屏列表；
   - 内存双重缓存与离线兜底池，抗平台 API 限流与网络波动；
4. **前端适配与模拟渲染**：
   - `/preview` 控制台提供平台一键切换、自定义 Webhook 数据一键填充与仿真渲染；
   - `/config` 面板支持选择不同榜单平台保存至设备。
